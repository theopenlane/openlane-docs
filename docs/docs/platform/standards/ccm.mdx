# Cloud Controls Matrix (CCM)

The Cloud Controls Matrix (CCM) is a set of security controls established by the Cloud Security Alliance (CSA) to assess and manage the risks associated with cloud computing services. CCM compliance means adhering to those controls, demonstrating that a cloud provider meets industry standards for data security and privacy within its infrastructure.

## Purpose

CCM provides a standardized framework for evaluating a cloud provider's security posture by examining areas such as access control, data encryption, and incident response.

## Assessment tool

The primary method to assess CCM compliance is a questionnaire called the Consensus Assessment Initiative Questionnaire (CAIQ), which helps organizations evaluate potential cloud vendors.

## Benefits

For buyers, a vendor's completed CAIQ gives you a control-by-control view of their cloud security practices before you sign, and the answers are comparable across vendors because everyone responds to the same questions. For providers, publishing a CAIQ to the CSA STAR registry answers the bulk of inbound customer security questionnaires once, instead of one bespoke spreadsheet at a time. CCM also maps its controls to ISO 27001 and the AICPA Trust Services Criteria, so evidence you already maintain for those audits carries over.
