# CC6.6

<ControlMeta
  refCode={"CC6.6"}
  category={"Security"}
  subcategory={"Logical and Physical Access Controls"}
  description={"The entity implements logical access security measures to protect against threats from sources outside its system boundaries."}
/>

## Points of Focus

<details>
<summary>Restricts Access</summary>

The types of activities that can occur through a communication channel (for example, FTP site, router port) are restricted.

</details>

<details>
<summary>Protects Identification and Authentication Credentials</summary>

Identification and authentication credentials are protected during transmission outside its system boundaries.

</details>

<details>
<summary>Requires Additional Authentication or Credentials</summary>

Additional authentication information or credentials are required when accessing the system from outside its boundaries.

</details>

<details>
<summary>Implements Boundary Protection Systems</summary>

Boundary protection systems (for example, firewalls, demilitarized zones, intrusion detection or prevention systems, and endpoint detection and response systems) are configured, implemented, and maintained to protect external access points.

</details>

## Example Control Objectives

- **Transmission security** - Data transmitted between systems is protected using encryption and secure protocols.

## Example Control Implementations

- **tailscale-vpn-access** - Infrastructure access is controlled through Tailscale mesh VPN. Implementation includes: - All production infrastructure requires Tailscale connection - Tailscale access control lists (ACLs) restrict access based on user role and team membership - Direct internet access to production infrastructure is prohibited - Device registration required in Tailscale admin console - Devices removed promptly upon employee departure
