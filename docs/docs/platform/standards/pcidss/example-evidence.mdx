# PCI DSS Example Evidence

The table below lists commonly evidenced control areas for PCI DSS and the artifacts that typically satisfy them; attach these to your controls as [evidence](/docs/platform/compliance-management/evidence/overview). Several areas apply only to service providers or to environments with wireless networks; mark those out of scope where they do not apply.

| Control Area | Example Evidence |
| ------------ | ---------------- |
| Architecture diagram | An approved architecture diagram |
| Annual risk assessment | The most recent completed risk assessment report |
| Targeted risk analysis | The documented targeted risk analysis for each control frequency you define yourself and for each customized approach control, identifying the assets protected, the threats addressed, the factors affecting likelihood and impact, and the justification for the chosen frequency, with evidence of review within the last 12 months |
| BCP/DR tests conducted annually | Results from the most recent business continuity or disaster recovery test |
| Firewall and router configuration standards | Documented testing and approval procedures for network connections and for firewall and router changes, plus example records showing a connection and a recent change were tested and approved |

| CDE network diagram review | Formal sign-off on the CDE network diagram with the reviewer's name and date |
| Dataflow diagram | The CDE data flow diagram, including the date it was finalized |
| Dataflow diagram review | Formal sign-off on the data flow diagram with the reviewer's name and date |
| Firewall configuration | The documented firewall and router configuration standards, plus screenshots showing firewalls match those standards |
| Network diagram consistent with firewall configuration | Firewall ruleset screenshots showing traffic restrictions match the network and data flow diagrams |
| Network management roles and responsibilities | A network administrator job description or a skills matrix for CDE network staff, plus configuration standards identifying firewall and router management responsibilities |
| Approved services, protocols, and ports | Configuration standards listing the services, protocols, and ports authorized in the CDE, with approval and justification for each |
