# NIST 800-53 Example Evidence

The table below lists commonly evidenced control areas for NIST 800-53 and the artifacts that typically satisfy them; attach these to your controls as [evidence](/docs/platform/compliance-management/evidence/overview).

| Control Area | Example Evidence |

| Separate environments | Screenshots from test and production environments showing they are distinct |
| Annual access reviews | Closed tickets documenting review of access lists for in-scope cloud environments, SaaS applications, infrastructure-as-code tools, and security tooling, with reviewer comments |
| Hardening standards | Infrastructure-as-code configurations applied when new infrastructure is deployed, plus formal documentation of deployment configurations |
| Annual risk assessment | The most recently completed risk assessment report |
| Risk remediation plan | Documented remediation plans for risks identified during the risk assessment |
| Annual penetration testing | Report from the most recent annual penetration test |

| Timely security communication | Screenshots from communication tools showing how security events are routed to the appropriate personnel |
| Management roles and responsibilities | The roles and responsibilities section of your information security policy |
| Offboarding checklist | A completed termination checklist or help desk ticket for a recently departed employee |
| Vendor register and agreements | A centralized vendor inventory with vendor name, relationship owner, services description, and risk rating, plus a sample executed agreement |
| Vendor compliance monitoring | Records showing vendor assurance reports (SOC 2 Type II reports, ISO 27001 certificates, or completed questionnaires) are obtained and reviewed annually |
| Authentication protocol | Screenshots of SSO login, password authentication, and MFA enforcement for employees, plus MFA availability for customers |
