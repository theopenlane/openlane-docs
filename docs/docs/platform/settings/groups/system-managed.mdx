We maintain three system-managed groups in every organization, with membership derived automatically from each user's organization role. They give you ready-made audiences for permission grants without maintaining membership by hand.

| Group | Who's In It |
| --- | --- |
| **Viewers** | All users with viewing permissions in the organization |
| **Admins** | All users with administrative (read and write access) privileges in the organization |
| **All Members** | Every user in the organization |

## Key Characteristics

Users are automatically added to these groups based on their roles; membership cannot be manually added, removed, or otherwise managed by users or administrators. These groups can be used to assign permissions to objects within the system, enabling streamlined access control.

:::tip
We recommend using these groups for broad permission grants because their membership updates automatically; you never have to maintain the member lists yourself.
:::
