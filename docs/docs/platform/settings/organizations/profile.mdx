# Organization Profile

The profile is how your organization presents itself in the console: its name, display name, description, and avatar. Navigate to `Organization Settings` → `Profile` to manage all of it.

## Name and Details

Update your organization's name, display name, and description from the profile page. One constraint to know: the organization **name** is its unique identifier and may be restricted after initial creation, while the display name shown throughout the console can change freely.

## Avatar

You can personalize your organization with a custom avatar that appears in the console. Upload an image file, or provide a URL to an image hosted elsewhere, and save your changes. If you provide both, the uploaded file wins.
