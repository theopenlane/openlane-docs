# ![okta integration](./assets/okta.png) Okta Integration Guide

If your organization uses Okta for identity management, this integration brings your directory, application assignments, and authentication policies into Openlane so you can run User Access Reviews, verify multi-factor authentication (MFA) enforcement, and maintain a current view of who has access to what.

## Key Capabilities

- **Directory and Application Sync:** Ingests users, groups, and application assignments from your Okta tenant, giving you the identity baseline for access reviews and entitlement validation.
- **Authentication Policy Visibility:** Surfaces sign-on policies, MFA requirements, and access rules so you can verify that authentication controls match your security standards.
- **Read-Only Access:** Ingests identity and policy data without changing Okta settings. Openlane reads your configuration and never modifies it.

## Prerequisites

- Okta API token with read permissions for users, groups, and system settings.
- Okta organization URL (e.g. `https://acme.okta.com`).

## Step-by-Step Setup

### Step 1: Create Okta API Token

<Steps>

1. In the Okta admin console, navigate to **Security** > **API** > **Tokens**.
2. Generate a new API token with org and policy read access.
3. Copy the token value (it is only shown once).

</Steps>

### Step 2: Connect in Openlane

<Steps>

1. Navigate to **Organization Settings** > **Integrations** and find **Okta**.
2. Click **Configure** and enter the required fields:

   | Field | Required | Purpose |
   |---|---|---|
   | `orgUrl` | Yes | Okta tenant base URL (e.g. `https://acme.okta.com`) |
   | `apiToken` | Yes | API token used for Okta API authentication |

3. Click **Save**.

</Steps>

## Validate Connection

After saving, Openlane runs a health check against Okta and displays the result on the **Installed** tab of the Integrations page. You should see a **Healthy** badge confirming connectivity. If the badge shows **Needs Attention**, review the troubleshooting section below.

## What Openlane Syncs

Openlane syncs your Okta directory (users, groups, application assignments) and authentication policy configuration (sign-on policies, MFA rules, access requirements). This gives you a continuously updated view of who has access to which applications, whether MFA is enforced where it should be, and whether sign-on policies match your security standards. This is the evidence an auditor expects when reviewing logical access and application access controls.

## Disconnect

To remove this integration, navigate to **Organization Settings** > **Integrations** and select the **Installed** tab. Open the menu on the integration card and select **Disconnect**. This removes stored credentials and stops all collection activity. You can reconnect later by configuring the integration again.

## Troubleshooting

- **Auth failures:** verify token validity and permission scope.
- **URL issues:** verify full HTTPS org URL format (e.g. `https://acme.okta.com`).
