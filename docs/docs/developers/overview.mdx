# Developer Documentation

Use this section to find implementation and operational guidance for the Openlane platform.

## Section Map

- [Getting Started](./getting-started/overview.mdx): local setup, stack startup, and CLI authentication
- [Schema & Codegen](./schema-and-codegen/graphql-and-codegen.mdx): making changes (schemas, code generation, migrations, hooks, and gotchas)
- [Architecture](./architecture/overview.mdx): how the system works (request lifecycle and the workflows engine)
- [Integrations](./integrations/overview.mdx): OAuth, SSO/OIDC, email, billing, and ingest patterns
- [Security](./security/overview.mdx): authentication, token management, encryption, and impersonation controls
- [Operations](./operations/overview.mdx): deployment, CI/CD, configuration, and runbooks
- [Contributing](./contributing/overview.mdx): docs style guidance and reference material

## How To Use This Docs Set

1. Start with `Getting Started` for a local environment.
1. Move to `Schema & Codegen` and `Architecture` when you are changing API, schema, or workflow behavior.
1. Use `Integrations`, `Security`, and `Operations` for implementation-specific workstreams.
1. Follow `Contributing` standards when updating docs.
