# Helper Repositories

The core service depends on shared libraries that we maintain in their own repositories. Knowing which library owns which behavior tells you where to look when you are tracing code that lives outside the core repo.

## riverboat
---
:::note[Repository]
https://github.com/theopenlane/riverboat
:::

Riverboat is the job queue used in Openlane based on the [riverqueue](https://github.com/riverqueue/river) project.

## gqlgen-plugins
---
:::note[Repository]
https://github.com/theopenlane/gqlgen-plugins
:::

[gqlgen](https://gqlgen.com/reference/plugins/) provides a way to hook into the
gqlgen code generation lifecycle. This repo contains several hooks that are used within
the core repo gqlgen generation process.

<Tabs>
    <TabItem value="resolver gen">
        This hook will override the default generated resolver functions with the
        templates for CRUD operations.
    </TabItem>
    <TabItem value="bulk gen">
        This hook creates resolvers that do bulk operations for a schema, for both bulk input and
        csv file upload input.
    </TabItem>
    <TabItem value="search gen">
        This hook creates search resolvers to search on fields within the ent schema. Fields in the schema
        that should be searchable by non-admins should include the annotation:

        ```go
        Annotations(
            entx.FieldSearchable(),
        )
        ```
    </TabItem>
</Tabs>

## entx
---
:::note[Repository]
https://github.com/theopenlane/entx
:::

A helper package for working with [ent](https://entgo.io/), which includes the following high-level utilities:

- [Mixin](https://entgo.io/docs/schema-mixin) used for assigning a different ID type than the one generated by `ent` (we use ULIDs)
- [Mixin](https://entgo.io/docs/schema-mixin) used for assigning some default columns (`created_at`, `created_by`, etc.; see the `mixin` directory for more details)
- A vanilla, drop-in setup for using `ent` with our standard tool chains `gqlgen`, `gqlgenc`, and some other helpers
- Soft-delete extension with cascade delete functionality added in
- enthistory extension for generating history tables using ent. The plugin adds on to your existing `entc` usage and enumerates over your current schemas to create new "history" schemas containing an inventory of the changes related to the existing tables.

## iam
---
:::note[Repository]
https://github.com/theopenlane/iam
:::

A Go library for interacting with [OpenFGA](https://openfga.dev/). It is comprised of two packages: `fgax`, a wrapper for the [OpenFGA go-sdk](https://github.com/openfga/go-sdk) and client libraries, and `entfga`, an [ent extension](https://entgo.io/docs/extensions/) that creates relationship tuples using [ent Hooks](https://entgo.io/docs/hooks/).

## httpsling
---
:::note[Repository]
https://github.com/theopenlane/httpsling
:::

The httpsling library simplifies the way you make HTTP requests. It's intended to provide an easy-to-use interface for sending requests and handling responses, reducing the boilerplate code typically associated with the net/http package.

## newman
---
:::note[Repository]
https://github.com/theopenlane/newman
:::

Newman is a package that allows you to send emails using different email providers. We use the `Resend` provider actively within Openlane projects.

## utils
---
:::note[Repository]
https://github.com/theopenlane/utils
:::

Utils holds common utility libraries for working within the Openlane ecosystem.
