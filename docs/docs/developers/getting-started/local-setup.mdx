# Local Setup

Before running Openlane locally, install the base tooling used across the repository.

## Required Tools

* [Go](https://go.dev/)
* [Task](https://taskfile.dev/)
* [Docker](https://www.docker.com/)
* [PostgreSQL client tools](https://www.postgresql.org/)

## Primary Frameworks and Services

Openlane development commonly touches:

| Tool | Used For |
|---|---|
| [ent](https://entgo.io/) | Schema-driven data modeling |
| [atlas](https://atlasgo.io/) and [goose](https://github.com/pressly/goose) | Database migrations |
| [gqlgen](https://gqlgen.com/) and [gqlgenc](https://github.com/Yamashou/gqlgenc) | GraphQL server and client generation |
| [openfga](https://openfga.dev/) | Authorization enforcement |
| [koanf](https://github.com/knadh/koanf) | Configuration management |

## Install Dependencies

From the repository root:

```bash
task install
```

After install, list available commands:

```bash
task
```

## IDE Build Tags

The core codebase uses [build tags](../schema-and-codegen/multi-module-structure.mdx#build-tags) for conditional compilation. Configure your IDE with the `cli,test,codegen,examples` tags, or functions gated behind them will appear undefined and your language server will flag imports as unused.

<Tabs groupId="ide" queryString>
    <TabItem value="vscode" label="VSCode">
        Add to `.vscode/settings.json`:

        ```json
        {
          "go.buildTags": "cli,test,codegen,examples"
        }
        ```
    </TabItem>
    <TabItem value="goland" label="GoLand">
        Navigate to _Settings > Go > Build Tags_ and add `cli,test,codegen,examples` as a comma-separated list.
    </TabItem>
</Tabs>
