# GraphQL Examples

This section provides ready-to-use GraphQL queries and mutations for working with Openlane objects programmatically. These pages mirror the platform documentation sections; each product area has a matching example page here.

- [Organizations](./organizations.mdx): create and manage organizations
- [Groups](./groups.mdx): groups, membership, and permission management
- [Tasks](./tasks.mdx): task creation and updates
- [Controls](./controls.mdx): control queries and management
- [Evidence](./evidence.mdx): evidence submission and tracking
- [Programs](./programs.mdx): program queries and relationships
- [Risks](./risks.mdx): risk queries, scoring, and treatment
- [Permissions](./permissions.mdx): authorization and access management

For the full schema reference, see the [GraphQL API Reference](/docs/api/graph-api), or experiment live in the [GraphQL Explorer](/graphql).

If you are new to the object model, read the [platform overview](/docs/platform/overview.mdx) for the domains and how they relate, then set up [API authentication](../security/api-tokens-and-pats.mdx); importing a standard and creating a program exercises most of the relationships.
